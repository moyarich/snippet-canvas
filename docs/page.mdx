# SnippetCanvas

Turn code selections into polished, multi-column images. Capture snippets in VS Code, arrange them in the composer, and export images or a PDF.

## Compose your code

Use Fit to size the canvas around your code, Grid for a fixed maximum number of columns, or Flow to pack columns by width. Customize colors, typography, window frames, captions, and watermarks.

## Try the composer

[Open the live composer](#/playground) to experiment with a sample snippet in your browser. The preview supports downloads and image copying when your browser permits it.

## Export and share

Export PNG, JPEG, or SVG page sets, or combine pages into a PDF. In VS Code, the extension prompts for the destination; the browser preview downloads files.
